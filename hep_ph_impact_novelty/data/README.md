# Data

All data files are excluded from the repository due to size. To reproduce them:

## papers.parquet (~90 MB)

Fetch all hep-ph papers from INSPIRE (2000-present, excluding conference proceedings):

```python
from parsing_data import get_data
import pandas as pd

df = get_data(from_Year=2000, categories=("hep-ph",), verbal=True)
df.to_parquet('data/papers.parquet', index=False)
```

Uses the [INSPIRE HEP API](https://inspirehep.net/api). No authentication required.

## embeddings.npy (~400 MB)

SPECTER2 embeddings for all papers. Requires a GPU (tested on an A10G):

```bash
python get_embed.py
```

Reads `data/papers.parquet`, writes `data/embeddings.npy`.

## embedding_transformed.npy (~2 MB)

2D UMAP projection of the embeddings. Run the following after loading the embeddings in the notebook:

```python
import umap
from sklearn.preprocessing import StandardScaler

reducer = umap.UMAP()
scaled_embeddings = StandardScaler().fit_transform(embeddings)
embedding_transformed = reducer.fit_transform(scaled_embeddings)
```

## umap_animation.html (~25 MB)

Interactive animation of the embedding space over time. Generated by:

```bash
python generate_animation.py
```

Reads `data/papers.parquet` and `data/embedding_transformed.npy`. Not tracked in the repository.
